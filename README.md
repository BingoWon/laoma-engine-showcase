# 老马喵务局 · 端侧智能体系统架构与全量工程物料全景拆解总成 (Showcase)

> **面向智能体操作指引（Agent Execution Manual）**  
> 本项目为**纯前端静态网页工程**（无需 `npm install`，无需构建），解压后直接启动 HTTP 服务即可运行与录屏。

---

## 1. 快速启动服务 (One-Line Start)

在解压后的项目根目录下执行以下命令：

```bash
# 启动本地静态 HTTP 服务 (端口可自定义，推荐 6188)
python3 -m http.server 6188

# 浏览器访问
open http://127.0.0.1:6188/
```

> **建议录屏环境**：Chrome / Edge / Safari 全屏或 1920×1080 视口分辨率。

---

## 2. 录屏与演示推荐操作流程 (Scripted Action Flow)

智能体在执行自动化操作或录屏演示时，建议按以下 6 个步骤进行演示：

### Step 1: 全景初始状态展示
- 打开页面后，镜头默认对焦中央装配核心台。
- 观察点：全画布 9 路视频流（3 路竖屏 + 6 路横屏）全自动静音循环播放，文字 100% 完整显示（无任何省略号）。

### Step 2: 中央真机 8 款工况截图即时切换
- 点击中央机身正下方的切换坞按钮：
  `01常态` -> `02触控` -> `03脏污` -> `04抚触` -> `05投喂` -> `06逗猫` -> `07体检` -> `08安睡`
- 观察点：中央手机屏幕无缝切换真实 APP 运行截图与状态胶囊。

### Step 3: 机械拆解滑块交互 (Exploded View)
- 操作顶部控制栏中央的“拆解度”滑块（或依次点击 `合拢` / `标准` / `全展` 按钮）：
  - 0%（合拢）：四大子系统聚拢回机身。
  - 70%（标准）：工程展开姿态。
  - 100%（全展）：最大极限拆解。
- 观察点：SVG 拓扑导引引线随模块位置动态重绘，无缝追踪。

### Step 4: Figma 式自由拖拽体验 (Draggable Nodes)
- 鼠标按住任意卡片（如“南部 15 位工程贡献者矩阵”或“西部物料清单”）并拖动。
- 观察点：卡片随鼠标移动，引线动态追踪，松开后保持新位置。

### Step 5: 顶部快捷对焦导航巡航 (Zone Camera Focus)
- 依次点击顶栏右侧的对焦按钮，平滑移动视窗：
  1. `🎯 核心`（中央机身装配台）
  2. `⚙️ 架构`（北部 4 层系统总成）
  3. `📸 基准`（西北实体猫咪物理建模样张）
  4. `🧪 候选`（东北 19.5:9 视觉与场景迭代阵列）
  5. `📦 物料`（西部 42 项 BOM 物料清单）
  6. `📱 真机`（东部 8 大真机工况大屏）
  7. `🎞️ 视频`（西南 6 路 16:9 动态工况观测站）
  8. `🎨 材质`（东南 Shader 贴图实验台）
  9. `👥 人员`（南部 15 位工程贡献者宽幅自适应矩阵）

### Step 6: 右侧工程探针抽屉 (Telemetry Drawer)
- 点击任意 3D 照护道具图标、团队成员卡片或材质贴图，右侧自动滑出探针抽屉，展示 100% 原生画幅零剪裁大图与技术参数。
- 点击抽屉右上角 `×` 或下方 `收起面板` 按钮关闭抽屉。
