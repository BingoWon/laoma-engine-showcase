## 一、系统核心特性

1. **Figma 式全组件自由拖拽（Draggable Nodes Engine）**：
   - 全画布 13 个独立分区与爆炸子模块全面支持按住自由拖拽。
   - SVG 动态导引虚线在拖动过程中每帧自动捕捉并重绘最新几何端点坐标。
2. **中央机身搭载真实应用界面（8 大工况切换坞）**：
   - 荣耀真机机身搭载真实应用实测截图（`Screenshot_20260919_174540_com_lyi_laomayoyo_MainActivity.JPG`）。
   - 提供 8 款真机工况即时切换控制坞（01常态、02触控、03脏污、04抚触、05投喂、06逗猫、07体检、08安睡）。
3. **100% 原始画幅 · 严格零剪裁（Zero-Crop Policy）**：
   - 彻底废除 `object-cover`，全局强制采用 `.no-crop-img`（`object-fit: contain`）。
   - 按物理形态族（19.5:9 手机全屏、16:9 影视宽屏、3:4/4:3 单反测光、1:1 正方代币、超宽贴图）有机聚类。
4. **全量资产 100% 覆盖（120/120 独特物料，143 个物理文件）**：
   - 涵盖全部正式物料、历史迭代版本、CV 脏污算法训练样张、未采用候选图及微纹理贴图。
5. **视频流专属工况观测站**：
   - [ASM-02] 媒体流管线实时播放 3 路 60fps 硬解视频流。
   - [VID-POSTERS] 动态工况站内嵌 6 组 16:9 动作捕捉硬件播放内核。
6. **Mac 原生触控板手势**：
   - 双指滑移平移画布、双指捏合以光标为中心执行 18% ~ 280% 无级平滑缩放。
